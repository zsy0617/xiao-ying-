# 贝雷帽女孩 · Windows 桌宠完整包

包含 dsh-pet-standalone-webm-chat 4.4.0 原版程序、贝雷帽女孩的 12 个透明循环动作、一键配置启动器和动作预览。

**Windows 10 / 11，64 位 x86-64。无需 Python、Node.js 或管理员权限。**

## 下载与使用

1. 打开 [Releases](https://github.com/zsy0617/xiao-ying-/releases/latest)，下载 **BeretGirl-Windows-v1.0.0.zip**。
2. 将 ZIP **完整解压**到普通文件夹。不要在压缩包窗口里直接运行。
3. 双击 **启动贝雷帽女孩.cmd**。首次启动会安装角色并选择“贝雷帽女孩”，随后启动桌宠。
4. 右键桌宠可以选择动作。被拖起摇晃由鼠标拖动触发。

已有桌宠正在运行时，请先从托盘退出后再启动本包。启动器会保留旧角色和现有设置；如需修改角色资源或主宠设置，会先在用户数据目录的 `beret-girl-backups` 中备份。全局模型连接、API 密钥和聊天设置不由启动器修改。

## 动作

待机眨眼、转头观察、奔跑、点击开心、被拖起摇晃、发呆、吃烤串、敲电脑、手势舞、摸黄眼小黑猫、戴黑框眼镜看书、抱大香菇抱枕趴地。

这些是少量绘画帧组成的短循环动作。日常动作可在原菜单中点播，也会按原桌宠调度出现。

## AI 聊天

纯桌宠功能不需要密钥。要使用聊天，在“桌宠设置 → 功能”启用 AI 对话（若尚未启用），再在“AI 与对话”填写你自己的模型连接和 API Key。此发布包不包含制作者的密钥、聊天记录或个人配置。

聊天记录按角色独立保存；旧角色的记录仍可切回原角色查看。

## 已装 dsh-pet 的用户

也可只下载 Release 中的 `beret-girl-character.zip`。解压后，将 `beret-girl` 文件夹放到：

```text
%APPDATA%\dsh-pet-standalone-webm-chat\characters\
```

再打开桌宠的角色菜单选择“贝雷帽女孩”。此普通角色 ZIP 使用解压方式安装，不用于 4.4.0 的分件素材安装按钮。

## 预览与恢复

完整包的“动作预览/index.html”可在支持透明 VP9 的浏览器中查看全部动作。

恢复原形象：在角色菜单选择原角色即可。移除此角色：先切回原角色、退出桌宠，再移走自己安装的 `characters\beret-girl` 文件夹。主程序、旧角色及旧聊天记录均可继续保留。
